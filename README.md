## 📌 1. 프로젝트 기획 배경 및 문제 정의

| 기획 질문 | 프로젝트 기획 내용 |
|---|---|
| **대상 사용자 (Target)** | **한국외국어대학교 신입생, 재학생, 방문객 및 교직원** |
| **기존 지도의 한계** | 네이버 지도나 카카오맵 등 기존 상용 지도 서비스는 도로명 주소와 큰 도로 위주로 설계되어 있어, **캠퍼스 내부 건물명(예: 교수학습개발원, 스마트도서관)이나 공식 건물번호(0, 1, 6, B, C 등)**를 검색하기 어렵고, 외대생들이 실제로 쓰는 **일상 별칭(미콤, 사관, 교학원 등)**이 전혀 매핑되지 않음. |
| **핵심 해결 과제 (Core Value)** | 1) **외대 공식 건물번호(0~11, B, C, D) 및 일상 별칭 완벽 검색**<br>2) **외대 부지만 정밀하게 둘러싼 시그니처 캠퍼스 둘레선(Polygon)**<br>3) **내 위치/정문에서 목적지 건물까지의 실제 도보 이동 경로선(Polyline) 그리기** |
| **최종 목표** | 별도의 앱 설치나 로그인 없이, 누구나 웹 브라우저에서 캠퍼스 위치를 한눈에 파악하고 목적지까지 도보 경로를 안내받을 수 있는 오픈형 인터랙티브 캠퍼스 맵 구축 |

## ✨ 2. 핵심 기능 상세

### ① 외대 공식 건물번호 & 재학생 일상 별칭 검색 시스템
- **공식 건물번호(12개 주요 건물) 완전 DB화**:
  - `0`: 대학본부 (본관)
  - `1`: 인문과학관 (인문관)
  - `2`: 교수학습개발원 (CTL)
  - `3`: 사회과학관 (사과관)
  - `5`: 법학관 (로스쿨)
  - `6`: 대학원 (대학원관)
  - `8`: 국제관
  - `9`: 스마트도서관 (중앙도서관)
  - `11`: 교수회관 (학생식당/교직원식당)
  - `B`: 미네르바 콤플렉스 (오바마홀, 체육관)
  - `C`: 사이버관 (사이버대학교 본부, 대강당)
  - `D`: 국제학사 (신학생회관, 기숙사)
- **외대생 맞춤형 별칭(Alias) 다중 검색**:
  - '미콤', '사관', '교학원', '중도', '오바마홀', '글로비돔' 등 검색 시 해당 건물로 즉시 부드럽게 화면 이동 (FlyTo)
  - **오매칭 방지 3단계 검색 우선순위 알고리즘**:
    - `1순위`: 건물번호 정확 일치 (예: `C` 검색 시 `CTL` 오매칭 차단 및 사이버관 직행)
    - `2순위`: 건물명 및 별칭 완전 일치
    - `3순위`: 키워드 부분 일치
- **원클릭 빠른 이동 칩(Quick Tags)**: 상단에 `#0`부터 `#D`까지 태그 칩을 배치하여 모바일에서도 원터치로 즉시 탐색 가능

### ② 한국외대 서울캠퍼스 정밀 둘레선 (Campus Boundary Polygon)
- 외대 서울캠퍼스의 실제 부지 외곽 경계선 좌표를 정밀 실측하여 지도 위에 네이비 시그니처 폴리곤 라인으로 시각화
- 상단 **`[🏫 캠퍼스 둘레선 (ON/OFF)]`** 토글 버튼을 통해 둘레선 표출 상태를 자유롭게 제어 가능
- 둘레선 영역 클릭 시 외대 서울캠퍼스 전체 개요 및 총 12개 주요 교육/행정 시설 정보 안내

### ③ 실시간 도보 이동 경로선(Foot Polyline) 그리기
- OSRM 보행로 라우팅 엔진(Open Source Routing Machine Foot Profile) 연동
- **[🚶 도보선 그리기]** 버튼 클릭 시:
  - **내 실시간 GPS 위치**(또는 GPS 미수신 시 **외대 정문**)에서 목적지 건물 입구까지 실제 보행 도로를 따르는 **파란색 네온 점선 경로선(Polyline)**을 지도 위에 렌더링
  - 도보 소요 시간(분) 및 이동 거리(m) 실시간 계산 표출
  - 카메라가 경로 전체를 한눈에 볼 수 있도록 자동 줌 조절 (`fitBounds`)
  - **[❌ 경로 지우기]** 버튼으로 손쉽게 지도 원상복구

### ④ 실시간 내 위치(GPS) 탐색 및 안심 보안
- 모바일/PC 브라우저의 Geolocation API 센서를 활용한 **`[📍 내 위치 찾기]`** 지원
- 내 위치 핀 및 오차 반경 원(Circle) 표시
- 건물을 선택했을 때 불필요한 위도/경도 숫자 노출을 배제하고, 사용자에게 꼭 필요한 건물 정보와 길찾기 버튼만 직관적으로 제공

### ⑤ 안정적인 오픈 지도 엔진 (Leaflet.js + CartoDB)
- API 키 만료나 도메인 심사 제한, 트래픽 과금 위험이 없는 **Leaflet.js** 및 고해상도 한글 타일맵(CartoDB Voyager) 채택
- 로컬 파일(`file://`) 실행 및 GitHub Pages 배포 환경 모두에서 100% 무결점 동작
